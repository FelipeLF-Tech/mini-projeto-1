# Projetos de Controle, Robótica e Programação — Felipe Lemos Fonseca

Coleção de projetos acadêmicos e protótipos, com descrição, fontes e estado de validação por pasta. Trabalhos assistidos por IA e participação em equipe são identificados nas descrições. Materiais de aula e dependências permanecem sujeitos às licenças dos autores; nenhuma licença geral foi atribuída automaticamente.

| Projeto | Finalidade |
|---|---|
| [Aeropêndulo](aeropendulo-controle-pid-supervisorio/) | Controle PID Arduino e supervisório Processing |
| [Dose Dupla](dose-dupla-esp32/) | Controle ESP32 por gamepad, ponte H/ESC e relé |
| [LiFi PCOM](lifi-comunicacao-optica/) | Comunicação óptica Arduino com emissor e receptor LCD |
| [Hospital](hospital-simulacao-concorrente/) | Concorrência e compartilhamento de recursos em Python |
| [Cadastro em C](cadastro-clientes-c/) | Cadastro de terminal com persistência em arquivo |
| [P3DX](p3dx-otimizacao-pid/) | Estudo acadêmico de ajuste PID com fmincon/GA; execução pendente |
| [VIGIL](vigil-digital-twin/) | Protótipo visual assistido por IA com dados simulados |
| [Georreferenciamento](georreferenciamento-contribuicao/) | Registro de contribuição em equipe e API introdutória recuperada |

Leia os limites de execução nos READMEs. Firmware requer teste de bancada; P3DX depende do ambiente de simulação. Credenciais e dados pessoais foram excluídos da seleção.
