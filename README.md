# Portfólio — organização em repositórios separados

Os novos projetos serão publicados individualmente, conforme orientação do autor. Este repositório contém somente este índice; os fontes ainda não foram enviados.

Projetos preparados: Aeropêndulo (controle PID e supervisório), Dose Dupla (ESP32), LiFi (PCOM), simulação concorrente de hospital, cadastro de clientes em C, P3DX (otimização PID), protótipo VIGIL e registro de contribuição em georreferenciamento.

A publicação dos pacotes aguarda criação dos repositórios de destino. O conteúdo de georreferenciamento recuperado é uma API introdutória e registro de participação em equipe; não é o sistema GeoSync completo.
