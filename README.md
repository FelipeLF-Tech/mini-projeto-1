## Autoria e estado dos projetos

Georreferenciamento registra participação em equipe: a maior parte do código do sistema foi desenvolvida pelos colegas de Computação. O repositório contém somente a API introdutória recuperada e não representa o GeoSync completo.

VIGIL é um protótipo assistido por IA com dados simulados. O hospital foi executado com 25 pacientes em teste acelerado. Os firmwares Dose Dupla foram revisados, mas aguardam compilação e teste em hardware. O estudo P3DX ainda tem pendências de reprodução dos resultados.
